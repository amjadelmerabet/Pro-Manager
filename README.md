# Pro Manager

Pro Manager is a web application for organizing personal projects and the tasks that make them up. It gives users a place to plan work, keep track of progress, and see what needs attention next.

## What you can do

- Create projects, describe them, set deadlines, and follow their progress from not started through completion.
- Break work into tasks, set priorities, and track each task as to do, doing, or done.
- Link tasks to projects or keep them independent.
- Find and organize work with search, filters, sorting, and different list, grid, board, or table views.
- Review project and task comments and activity history, and manage account details and preferences.
- Choose between Classic and Modern layouts for the signed-in workspace.

The app also includes public pages introducing its features, pricing, and background, alongside sign-in and sign-up pages.

## Repository guide

- `client/` contains the web interface, including public pages and the authenticated project and task workspace.
- `server/` contains the application service for accounts, projects, tasks, comments, activity, and access control.

Pro Manager is useful for anyone who wants a clear, lightweight way to keep personal projects and day-to-day tasks organized in one place.
